# Dependency Map

```text
V0.0 Foundation + Build Dashboard
  -> V0.1 Data Model + Auth
    -> V0.2 Public Shop
    -> V0.3 Honoree Reveal
    -> V0.4 My People + Buyer Tools
    -> V0.5 Artist Studio
    -> V0.6 Admin + Ops
      -> V0.7 QA + Observability
        -> V1.0 Launch-Ready Instance
```

Foundation establishes the project shape and dashboard. Data/Auth creates the backend contract. Feature lanes then move in parallel where possible. QA and production ops harden what exists rather than inventing new product scope.
